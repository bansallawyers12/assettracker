# Emails

## Emails index filters collapse behind a Filters button
Inbox filters stay hidden by default. Toggle with a Filters control that shows the lucide-filter icon plus the word Filters (badge when active). Expand automatically when any filter query is present. When open, keep Search / From / To / Label / Apply on one compact horizontal row (wrap on narrow screens). Do not restore always-visible stacked filter controls above the mailbox.
